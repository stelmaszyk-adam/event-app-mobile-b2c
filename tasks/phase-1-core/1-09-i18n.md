# Task 09: Internationalization (i18n)

**Phase:** 1 — Core
**Priority:** P0
**Dependencies:** `tasks/phase-0-preparation/0-00-component-library.md`
**Reference:** `documentation/ROADMAP-mobile-b2c.md §1.9`

---

## Objective

Wire up `react-i18next` with PL as the primary language and full EN support. All UI strings must come from translation files.

## Deliverables

- [ ] P0 Configure `react-i18next` + `react-native-localize` for device locale detection
- [ ] P0 Create `locales/pl.json` — all UI strings (buttons, labels, filters, error messages, onboarding)
- [ ] P0 Create `locales/en.json` — full English translation of all keys in `pl.json`
- [ ] P0 Device locale detection: default to PL if device locale starts with `pl-`; otherwise PL for MVP (single-country)
- [ ] P0 Extract ALL hardcoded Polish strings from existing components into translation keys
- [ ] P0 Language switcher in User Profile settings (PL / EN)
- [ ] P0 Persist language preference locally (MMKV or AsyncStorage) and sync to backend (`PATCH /users/me` with `language`)

## Acceptance Criteria

- Switching to EN in profile settings changes all visible strings without app restart
- No hardcoded Polish or English strings remain in component source (verified by grep)
- Device set to `pl-PL` locale opens the app in Polish by default
